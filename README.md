### 1. [MaNGA-DESOM](./MaNGA-DESOM/)
> **Deep Embedded Self-Organizing Maps applied to integral field spectroscopy (IFU) from the SDSS-IV MaNGA survey.**

Strict replication and high-performance engineering architecture for the unsupervised classification of galaxy spectral diversity, based on the methodology of *Teimoorinia et al. (The Astronomical Journal / [arXiv:2112.03425](https://arxiv.org/abs/2112.03425))*.

* **Model Architectures:**
  * **DESOM-1:** 1D Convolutional Autoencoder + SOM layer ($15 \times 15$ grid) for unsupervised representation learning and latent compression of rest-frame spectra in the range `[3650, 8950] Å`.
  * **DESOM-2:** 2D Convolutional Autoencoder + SOM layer ($10 \times 10$ grid) for clustering spatial galaxy fingerprints generated by DESOM-1 to capture global morphological and spectral diversity.
* **Key Engineering Highlights:**
  * **Modular 4-Stage Pipeline:** End-to-end execution via CLI (`desom/cli/`) covering raw data ingestion, Voronoi binning, consolidation, and DESOM training.
  * **Multi-Core CPU Parallelism:** Distributed download, FITS LOGCUBE decompression, and Voronoi binning via `ProcessPoolExecutor` with strict `spawn` context isolation.
  * **Interactive Astronomical Web Dashboard:** Native Python web UI (`app.py`) featuring interactive spectral inspections and galaxy footprint projections in dark mode.
  * **Automated Testing Suite:** Unit and integration tests powered by `pytest` under `tests/test_pipeline.py`.
  * **Dual Storage & Colab Support:** Flexible storage (local disk or Google Drive) with GPU acceleration support via `Pipeline_Unificado.ipynb`.
* *See full documentation and CLI usage in [MaNGA-DESOM/README.md](./MaNGA-DESOM/README.md).*

### 2. [Self-Organizing Maps (SOM)](./Self-Organizing-Maps/)
> **Ground-up implementation of Kohonen Self-Organizing Maps and unsupervised reconstruction of the Hertzsprung-Russell diagram.**

Rigorous theoretical and empirical study of vector quantization and topology-preserving projection for non-linear manifolds, without relying on high-level ML libraries.

* **Implementation Details:**
  * Built from fundamental mathematical principles using pure Python and NumPy.
  * Neighborhood topology support for both **square** and **hexagonal** lattice structures.
  * Full interpretability diagnostics: **Unified Distance Matrix (U-Matrix)**, **component planes**, and **hit density maps**.
  * Quantitative topological metrics: Quantization Error ($QE$) and Topographic Error ($TE$).
  * Two-level clustering (SOM + K-Means) and grid search for hyperparameter optimization.
* **Astrophysical Application:**
  * Unsupervised mapping of 240 stars characterized by 4 astrophysical observables (temperature, luminosity, radius, and absolute magnitude).
  * Autonomous reconstruction of the evolutionary branches of the **Hertzsprung-Russell (H-R) diagram**, recovering known stellar physics without labels.
* *See full documentation in [Self-Organizing-Maps/README.md](./Self-Organizing-Maps/README.md).*

## Quickstart Guide

### 1. Clone the repository
```bash
git clone https://github.com/AngelGab3/Deep-Learning-Projects.git
cd Deep-Learning-Projects
```

### 2. Set up a virtual environment
Python 3.8+ is recommended:
```bash
python3 -m venv venv
source venv/bin/activate  # On macOS / Linux
# venv\Scripts\activate   # On Windows
```

### 3. Run the Projects

#### A. Explore MaNGA-DESOM
```bash
cd MaNGA-DESOM
pip install -r requirements.txt

# Launch the interactive Web Dashboard:
python3 app.py --port 8050
# Open http://localhost:8050 in your browser

# Or execute the complete pipeline via CLI:
python3 -m desom.cli.run_all --workers 4
```

#### B. Explore Self-Organizing Maps
```bash
cd Self-Organizing-Maps
pip install numpy matplotlib scipy scikit-learn jupyter
jupyter notebook Self_Organizing_Maps.ipynb
```
